# Rebranding Guide

This guide will help you create a new project based on this codebase with different branding.

## Step-by-Step Process

### 1. Create New Project Directory

```bash
# Navigate to your parent directory
cd /Users/rouzbeh/Desktop/Development

# Copy the entire project (excluding node_modules and .git)
cp -r propfind.ai your-new-project-name
cd your-new-project-name

# Remove old git history
rm -rf .git

# Remove node_modules (you'll reinstall)
rm -rf node_modules
```

### 2. Initialize New Git Repository

```bash
git init
git add .
git commit -m "Initial commit: rebranded from propfind.ai"
```

### 3. Files to Update for Branding

#### A. Package Configuration
- **`package.json`**: Change `"name": "propfind.ai"` to your new project name

#### B. Application Files
- **`src/app/page.tsx`**:
  - Line 53: Logo alt text: `"PropFind Logo"` → Your brand name
  - Line 63: Title: `"PropFind"` → Your brand name
  - Line 66: Tagline: `"your personal real estate assistant"` → Your tagline
  - Line 91: Description: `"PropFind.ai is your everyday assistant..."` → Your description

- **`src/app/layout.tsx`**:
  - Line 16: `title: "Create Next App"` → Your app title
  - Line 17: `description: "Generated by create next app"` → Your app description

- **`src/app/admin/page.tsx`**:
  - Line 11: `"Manage your PropFind application"` → Your brand name

#### C. Assets
- **`public/logo.svg`**: Replace with your new logo (keep the same filename or update references)

#### E. Colors (Optional)
- **`src/app/globals.css`**: 
  - Update CSS custom properties in `:root` and `.light` sections if you want different colors
  - Current theme uses dark blue/green tones - adjust to match your brand

### 4. Environment Variables

If you have a `.env` or `.env.local` file, update:
- Any brand-specific environment variables

### 5. README.md

Update `README.md` with:
- Your project name
- Your project description
- Your specific setup instructions

### 6. Install Dependencies

```bash
npm install
```

### 7. Test Your New Project

```bash
npm run dev
```

Visit `http://localhost:3000` to see your rebranded application.

## Quick Find & Replace Checklist

Use these search terms to find all instances:
- `PropFind` (case-sensitive)
- `propfind` (case-sensitive)
- `propfind.ai`
- `real estate assistant` (or your domain-specific text)
